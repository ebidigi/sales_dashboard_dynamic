# 要件定義書

## プロジェクト名
稼働報酬チーム営業KPI確認シート

## 目的
Google スプレッドシートで管理している営業KPIデータを、BIツールのように視覚的に確認できるダッシュボードを提供する。

---

## 機能要件

### 1. データ取得
- Google スプレッドシートの「月次ビュー」シートからデータを取得
- Google Apps Script Web App API経由でJSONデータを取得
- ブラウザから直接APIを呼び出し（CORS対応）

### 2. KPI表示

#### 2.1 サマリー表示
| 項目 | 説明 |
|------|------|
| 標準進捗 | 経過日数/全稼働日 × 100% |
| 架電進捗 | 実績架電数/目標架電数 × 100% |
| アポ進捗 | 実績アポ数/目標アポ数 × 100% |
| 進捗差分 | アポ進捗 - 標準進捗 |

#### 2.2 担当者別表示
- 担当者名（案件名）形式で表示
- 架電進捗バー（標準進捗ライン付き）
- アポ進捗バー（標準進捗ライン付き）
- 詳細数値（架電数、アポ数、転換率）

### 3. フィルタリング機能
- **案件フィルター**: 全案件 / 各案件名
- **担当者フィルター**: 全員 / 各担当者名
- フィルター適用時、カードとグラフが連動して更新

### 4. グラフ表示
- 架電進捗 vs アポ進捗 比較棒グラフ（標準進捗の点線付き）
- 架電進捗率ランキング（横棒グラフ）
- アポ進捗率ランキング（横棒グラフ）

### 5. 進捗分析
- 全体状況判定（順調/要注意/遅延）
- 達成人数/未達人数のカウント
- トップパフォーマー表示
- 要フォロー者表示

---

## 非機能要件

### 1. パフォーマンス
- 初期読み込み: 3秒以内
- データ更新: 2秒以内

### 2. 対応ブラウザ
- Chrome（推奨）
- Safari
- Firefox
- Edge

### 3. レスポンシブ対応
- デスクトップ（1024px以上）
- タブレット（768px〜1023px）
- モバイル（767px以下）

### 4. セキュリティ
- APIは匿名アクセス許可（社内データのため注意）
- HTTPS通信

## データ仕様

### スプレッドシート構造（月次ビュー）

| 行 | 内容 |
|----|------|
| 1行目 | 空行 |
| 2行目 | ヘッダー情報（標準進捗、経過日数など） |
| 3行目 | 空行 |
| 4行目 | カラムヘッダー |
| 5行目〜 | 担当者データ |
| 最終行付近 | 計、計（拡張） |

### カラム構成

| 列 | 内容 |
|----|------|
| B | 担当者名 |
| C | 案件名 |
| D | コールペース |
| E | アポペース |
| F | 売上 |
| G | 目標架電数 |
| H | 実績架電数 |
| I | 架電進捗率 |
| J | 目標アポ数 |
| K | 実績アポ数 |
| L | アポ進捗率 |
| M | 実績PR |
| N | 時間当たり架電目標 |
| O | 時間当たり架電実績 |
| P | 架電→アポ目標 |
| Q | 架電→アポ実績 |
| R | 架電→着電率 |
| S | 着電→アポ率 |
| T | 目標稼働時間 |
| U | 実績稼働時間 |

### 進捗判定ロジック

```javascript
function getStatus(value, standard) {
    if (value >= standard) return 'success';      // 緑
    if (value >= standard * 0.8) return 'warning'; // 黄
    return 'danger';                               // 赤
}
```

## 制約事項

1. スプレッドシートの構造変更時はGASコードの修正が必要
2. GAS Web Appの実行クォータ制限（1日あたり20,000回）
3. APIレスポンスは最新のスプレッドシートデータを返す（キャッシュなし）
